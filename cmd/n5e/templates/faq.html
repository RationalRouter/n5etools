FAQ

Frequently asked questions

What exactly is N5etools?

Think of it as a fast, searchable digital reference library for your games. It's a local web app designed to look and feel like classic 5etools, bringing the sourcebooks into one clean, responsive interface so you don't have to flip through multiple PDFs or heavy spreadsheets during a session.

Does this replace the official N5e Google Sheets?

Not at all! This is meant to be a companion tool. While the sheets are amazing for character building and active tracking, N5etools is designed to be the ultimate, fast-loading knowledge base for players and GMs to look up rules, jutsu, items, and features on the fly.

How do the books stay updated?

Behind the scenes, the app is built to automatically check for the latest versions of the text, extract the data, and update its own internal reference library. You won't need to manually import new updates when a book changes.

Do I need an internet connection to use it?

Once you have it downloaded and set up on your machine, it runs as a local server, meaning the core reference library works entirely offline. You'll only need internet when the app checks for new sourcebook updates.

I found a typo or an incorrect rule. Can you fix it?

Because the app extracts text directly from the source material, errors usually fall into two categories. If the text is wrong in the actual PDF, that's up to the N5E design team to patch. But if the app accidentally mangled the text or put a jutsu in the wrong category, that's a coding bug on my end! Please report those so I can fix the layout.

Can you add homebrew rules or custom clans?

Right now, the focus is entirely on getting the official, core N5E source material running perfectly and updating seamlessly. Once the foundation is rock-solid, I might look into ways for users to add their own custom data, but for now, we're sticking to the official books.

Why did you build this if you don't even play the game?

Short answer: I wanted to help a friend. I saw how much manual, exhausting effort went into organizing the data behind the scenes just to keep the game running smoothly for everyone. I realized I could use my programming background to automate the tedious parts, letting the creators focus on making the game fun and letting you guys focus on playing it. See About the Creator for the longer version, or Technical Overview if you want the actual how-it-works details.
